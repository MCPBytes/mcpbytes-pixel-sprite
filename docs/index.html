MCPBytes Pixel Sprites Generator

Describe a character and get a pixel-art sprite sheet: walk cycles facing down, left, right and up, four still poses, looping walk previews and ready-made Godot and Unity imports. It runs on your own NVIDIA GPU, from the command line or from any MCP client.

The sheet

Sixteen 32×32 cells, one character.

Every sheet is a 128×128 PNG with one shared palette. Columns 1–3 of each row are walk poses; column 4 holds a still pose.

  1. Facing down: three walk poses, then arms raised.
  2. Facing left: three walk poses, then jump left.
  3. Facing right: three walk poses, then jump right.
  4. Facing up: three walk poses, then lying down.

The walk previews loop poses 1, 2, 3, 2: three drawn poses in a four-frame cycle. Results come marked unreviewed or needs_review, never approved: check anatomy, facing and transparency yourself.

FileWhat it holds
raw_N.pngThe model's 512×512 render, before any processing.
sprite_N.pngThe 128×128 sheet: transparent background, one shared palette.
sprite_N.jsonFrame rectangles and pivots, animations, palette, QA status and warnings.
sprite_N.zipSheet, 16 frames, 4 walk GIFs, manifest, QA and provenance, a Godot 4 scene, a Unity 6 importer and IMPORTING.md.
generation.jsonEffective options, seeds and model revisions (your description is left out).

Get started

Your GPU, or ours.

On your NVIDIA GPU

  • A CUDA 12.8 driver (R570 or newer) on Windows or Linux.
  • About 16 GB of disk for the model files, downloaded once from Hugging Face at pinned commits.
  • uv, or Python 3.11–3.13 with pip.
uvx --torch-backend=auto mcpbytes-pixel-sprite download
uvx --torch-backend=auto mcpbytes-pixel-sprite generate \
  "A forest ranger with a green hood" --seed 42

From any MCP client

Run download once, then add the server; it provides one tool, create_pixel_sprite.

{
  "mcpServers": {
    "pixel-sprite": {
      "command": "uvx",
      "args": ["--torch-backend=auto",
               "mcpbytes-pixel-sprite", "mcp"]
    }
  }
}

No NVIDIA GPU?

--cloud sends the job to MCPBytes GPUs for prepaid credits, with the same files back. Create an API key at console.mcpbytes.com. 

export MCPBYTES_API_KEY=...
uvx mcpbytes-pixel-sprite generate "A forest ranger" --cloud

Options

--variants 1-4, --reference image.png, --opaque, --palette-colors 16|32|64, --palette, --frame-duration-ms and --seed. The README covers each one, the GPU memory modes and the pinned models.
